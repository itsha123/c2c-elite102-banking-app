# SigmaBank - The World's First Terminal UI Bank (Code2College Elite 102 Project)
Terminal UI connected to MySQL database.
Bugs to be expected for edge cases, works in normal cases. (too tired and too late to fix them)
Features:
 - Create Accounts
 - Delete Accounts
 - Deposit Money
 - Withdraw Money
 - Securely Hashed Passwords
 - View balance at top of TUI  

To setup, edit hardcoded `db` variable in code with your credentials, then use `python main.py`
